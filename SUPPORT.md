# Support

## Getting help

- **Usage questions / configuration help**: open a
  [GitHub Discussion](https://github.com/rotsl/biotrace/discussions) or an
  issue using the "Question" template.
- **Bug reports**: open a
  [GitHub issue](https://github.com/rotsl/biotrace/issues/new/choose) using
  the bug report template. Include your `.github/biotrace.yml`, the
  workflow file, and the relevant Action run log.
- **Feature requests**: open a GitHub issue using the feature request
  template.
- **Security vulnerabilities**: do **not** open a public issue — see
  [SECURITY.md](SECURITY.md).

## Before opening an issue

Check the README's [Troubleshooting](README.md#troubleshooting) and
[Configuration Reference](README.md#configuration-reference) sections —
many "why isn't X working" questions (missing labels, no comment, AI
showing `no-key`, fork PR behaviour, `dist/index.js` out of date) are
already covered there.

## Response times

BioTrace is maintained on a best-effort basis. There is no guaranteed
response time or SLA.
